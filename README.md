This is an **evolving learning repository**. It collects the work I produce as I move through my training, and it grows continuously.

## 📚 Concept-Wise Examples

Alongside my own work, each main folder contains **numbered concept folders** written as beginner-friendly references.

| | |
|---|---|
| `HTML/` | 8 concept folders |
| `HTML&CSS/` | 10 concept folders |
| `JAVASCRIPT/` | 13 concept folders (including 3 mini projects) |

Every example is designed to be:

- **Simple** — one file where possible, no build step, no dependencies
- **Easy to understand** — one concept per folder, nothing combined
- **Practical** — small real examples rather than abstract snippets
- **Well organised** — numbered folders, consistent `index.html` / `style.css` / `script.js` names
- **Commented where useful** — comments explain *why*, not every obvious line
- **Easy to run** — open the file in a browser; nothing to install

JavaScript examples print their results both **on the page** and in the browser console, so the output is visible immediately.

The aim is to make this repository useful to another student who wants a clear, minimal reference — not just a record of my work.

<a id="approach"></a>

## 🧭 Learning Approach

```text
Learn  →  Practice  →  Build  →  Improve  →  Repeat
```

I focus on understanding concepts through **implementation rather than only theoretical study**.
Reading about Flexbox is not the same as using it to solve a layout problem, and reading about
Promises is not the same as handling a failed API request.

So the cycle is: learn a concept, write it out, use it in something small, notice what is awkward,
and improve it. That repetition is what turns reading into skill.
