Key CSS Properties Used

  • display: flex + justify-content: space-between — layout of the navbar
  • margin-left: auto — pushes the links to the right side
  • list-style: none — removes the bullet points from the <ul>
  • text-decoration: none — removes the underline from links
  • position: sticky — keeps the navbar visible while scrolling
