Important CSS for Cards

  • border-radius: 12px — rounded corners
  • box-shadow: 0 4px 10px rgba(0,0,0,0.1) — a soft shadow
  • padding: 20px — space between the border and the content
  • overflow: hidden — keeps a top image inside the rounded corners
  • transition — makes a hover effect smooth instead of sudden
