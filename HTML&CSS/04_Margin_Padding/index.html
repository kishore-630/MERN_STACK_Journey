Margin and Padding

Padding is the space inside the border, between the border and the content.

Margin is the space outside the border, between this element and other elements.

4. Collapsing Margins

When two blocks have margins, the browser uses the larger one instead of adding them. This is called margin collapsing.

Block A — margin-bottom: 40px
Block B — margin-top: 20px (40px is used, not 60px)
