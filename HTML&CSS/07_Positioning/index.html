CSS Positioning

The position property decides how an element is placed on the page.

1. position: static (the default)

Every element starts as static. It flows normally in the document, and top / left do nothing.

static — flows normally
second static box

2. position: relative

The element stays in its normal flow, but it can be shifted using top/left/right/bottom. Other elements do not move to fill the gap.

relative — moved 20px right and 20px down

The paragraph below did not move up into the gap.

3. position: absolute

An absolute element is taken out of the normal flow. It is positioned relative to its nearest positioned ancestor (or the page if none exists).

4. position: fixed

A fixed element stays in the same place on the screen even when you scroll. Notice the button in the bottom-right corner — scroll down and it does not move.

5. position: sticky

A sticky element scrolls normally, but it "sticks" to a position once you scroll past it.

6. Quick Reference

Value In normal flow? Reference point Use it for
static Yes — The default
relative Yes Its normal position Small shifts, hover effects
absolute No Nearest positioned ancestor Badges, tooltips, dropdowns
fixed No The viewport (screen) Sticky navbars, chat buttons
sticky Yes Its normal position Section headers, table headers
