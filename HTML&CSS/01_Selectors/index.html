CSS Selectors

A selector chooses which HTML element(s) the CSS style will be applied to.

1. Element Selector

This paragraph uses the element selector p.

Every paragraph on the page is styled the same way.

2. Class Selector (most used)

This paragraph has class="highlight", so it is highlighted.

This paragraph has no class, so it is normal.

A class can be reused many times

Second highlighted paragraph.

3. ID Selector

This heading uses an ID

An ID must be unique on the page, so it is used for one element only.

4. Grouping Selector

Grouping means applying the same style to several selectors at once (comma separated).

5. Descendant Selector

This paragraph is inside a div with class="box", so it gets the special style.

This paragraph is outside the box, so it is normal.

Combinators explained

  • .box p — any paragraph inside .box (descendant)
  • .list-demo > p — only a direct child paragraph (child)
  • h2 + p — the paragraph right after an h2 (adjacent sibling)
