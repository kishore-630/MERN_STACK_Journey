The CSS Box Model

Every element on a page is a box. Understanding this box is the key to CSS layout.

margin (outside the border)
border
padding (space inside the border)
content

Width and Height

The width and height set the size of the content area only (unless box-sizing is changed).

This box is 200px wide and 80px tall (content area).

box-sizing: border-box (recommended)

By default CSS uses content-box, which means padding and border are added to the size. Using border-box makes padding and border included in the size instead.

With box-sizing: border-box — total width stays 300px even with padding and border.
With box-sizing: content-box — total width becomes 300px + 40px padding + 6px border.

Border

Border can have a style, a width and a color.

solid border
dashed border

Min-Width, Max-Width and Overflow

This box has max-width: 400px, so it never grows wider than 400px even on a large screen.

Common Box Model Fix

Most developers add this small reset at the top of a stylesheet:

* {
    box-sizing: border-box;
}

It makes every element include padding and border inside its declared width, which makes layouts much easier to control.
