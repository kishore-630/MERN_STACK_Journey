Responsive Design

Responsive design means the page looks good on every screen size — phone, tablet and desktop.

1. The Viewport Meta Tag

Always add this inside <head>:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

2. Relative Units

Instead of fixed pixels, use units that respond to the screen:

  • % — percentage of the parent
  • vw / vh — 1% of the viewport width / height
  • rem — relative to the root font size (usually 16px)
  • em — relative to the parent font size
This box uses width: 50% and padding: 3vw

3. clamp(), min() and max()

These let you set a minimum, a maximum and a flexible value — without media queries.

clamp() heading — resizes smoothly
min(100%, 600px) — never wider than 600px

4. max-width (the simplest responsive fix)

This box has max-width: 500px so it does not stretch on large screens.

5. Responsive Image

An image with max-width: 100% will shrink to fit its container.

6. Media Queries

Media queries apply CSS only when the screen matches a condition. Shrink your browser window to see the boxes below change size.

This box changes color and padding at 768px and at 480px.

7. Common Breakpoints

Device Screen width Typical breakpoint
Mobile up to 600px max-width: 600px
Small tablet 601px – 768px max-width: 768px
Desktop 769px and above min-width: 769px

8. Flexbox That Wraps Automatically

Often you do not need media queries at all. Flexbox with flex-wrap: wrap and flex: 1 1 200px adapts by itself.
