How a basic HTML file is organised

  • <html> — the root element. Everything goes inside it.
  • <head> — information about the page (not shown on the page).
  • <title> — the text shown on the browser tab.
  • <body> — everything the user actually sees.

Tags always come in pairs

An opening tag, some content, and a closing tag:

<p>Hello</p>  →  the p tag opens, "Hello" is the content, and the tag closes.

<br> is different — it is an empty tag, so it has no closing tag.
