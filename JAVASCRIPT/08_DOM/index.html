8. DOM Manipulation

DOM = Document Object Model. It is the live tree structure of your HTML page. With JavaScript you can find elements on the page and change them.

1. Selecting Elements

MethodWhat it selectsReturns
getElementById("x")One element by its idOne element or null
querySelector(".x")First matchOne element or null
querySelectorAll(".x")All matchesNodeList (like an array)

2. Changing Content

  • el.textContent = "new text" — safe, treats text as plain text
  • el.innerHTML = "<b>new</b>" — also works with HTML tags

3. Changing Styles and Attributes

  • el.style.color = "red"
  • el.classList.add("highlight")
  • el.setAttribute("title", "hello")
