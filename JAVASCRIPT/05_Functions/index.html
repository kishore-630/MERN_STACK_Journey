5. Functions

A function is a reusable block of code that runs only when you call it.

1. Function Declaration

function greet(name) {
    return "Hello " + name;
}

2. Function Expression

The function is stored in a variable, so it can be passed around like any other value.

const add = function (a, b) {
    return a + b;
};

3. Arrow Functions

A shorter syntax. Very common in modern JavaScript.

const add = (a, b) => a + b;

4. Parameters and Arguments

  • Parameters are the names in the function definition: function add(a, b)
  • Arguments are the real values you pass in: add(5, 3)
  • return sends a value back to where the function was called

5. Default Parameters

Used when the caller does not pass a value.

function greet(name = "Guest") { ... }

6. Rest Parameters (...)

Collects many arguments into an array.

function total(...numbers) { ... }
