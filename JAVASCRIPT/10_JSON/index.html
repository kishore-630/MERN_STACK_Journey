10. JSON

JSON = JavaScript Object Notation. It is a text format for sending and storing data. It looks almost exactly like a JavaScript object, but it is a string, not an object.

Rules of JSON

  • Keys must be in double quotes: {"name": "Kishore"}
  • Values can be: string, number, boolean, null, array, object
  • No trailing comma at the end
  • No comments allowed
  • Single quotes are NOT allowed — always use double quotes

Two Functions You Need

FunctionDirectionResult
JSON.stringify(object)JavaScript → JSON texta string
JSON.parse(jsonText)JSON text → JavaScriptan object

When is JSON used?

Whenever data is sent to a server or received from a server. When you call an API, the response you get back is almost always JSON.
