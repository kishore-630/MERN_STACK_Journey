1. Variables and Data Types

JavaScript has three ways to create a variable: var, let and const. In modern JavaScript, always use let and const.

Keyword Can the value change? Scope
var Yes Function (old, avoid it)
let Yes Block { }
const No (cannot be reassigned) Block { }

Data Types

  • String — text, written in quotes: "hello"
  • Number — whole numbers and decimals: 25, 3.14
  • Boolean — only two values: true or false
  • Undefined — a variable that has no value yet
  • Null — intentionally "no value"
  • Object — a collection of key-value pairs
  • Array — an ordered list of values

Note: typeof is used to find the data type of a value.

Output

Open the browser console (press F12) to see the same values printed with console.log().
