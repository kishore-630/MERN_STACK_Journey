9. Events

An event is something that happens on the page — a click, typing, pressing a key, submitting a form. You use addEventListener() to run your code when it happens.

element.addEventListener("eventName", function () {
    // runs when the event happens
});

Common Events

EventFires when
clickAn element is clicked
inputThe user types in a text field
changeThe value of a select/checkbox changes
submitA form is submitted
keydownA key is pressed down
mouseoverThe mouse moves over an element
focusAn input gets focus (clicked into)
