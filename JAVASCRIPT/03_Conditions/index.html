3. Conditions (if / else)

Conditions let your code make decisions. The value being checked is called a condition, and it must be true or false.

1. if

Runs the block only when the condition is true.

if (condition) {
    // this runs only if condition is true
}

2. if ... else

Runs one block or the other — never both.

3. else if

Used when you need to check more than two possibilities. The first matching condition wins, so order matters.

4. switch

Useful when you are comparing one variable against many fixed values.

switch (day) {
    case "Monday": ...
    case "Tuesday": ...
    default: ...   // runs if nothing matched
}

Remember: always use === (three equals) instead of == when comparing.
