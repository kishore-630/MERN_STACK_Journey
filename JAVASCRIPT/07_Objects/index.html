7. Objects

An object stores related values together as key-value pairs.

let student = {
    name: "Kishore",
    age: 21
};

1. Key-Value Rules

  • Keys and values are separated by a : (colon)
  • Each pair is separated by a , (comma)
  • Keys are always in quotes unless they are a single word

2. Accessing Values

  • student.name — dot notation (most common)
  • student["name"] — bracket notation (needed for keys with spaces)

3. Useful Object Methods

  • Object.keys(obj) — all the keys
  • Object.values(obj) — all the values
  • Object.entries(obj) — all key-value pairs

4. Destructuring

A short way to take values out of an object into separate variables.

const { name, age } = student;

5. Spread Operator

Used to copy an object or merge objects together.
