4. Loops

Loops repeat a block of code many times without writing it again and again.

1. for loop

Use when you know how many times to repeat.

for (let i = 1; i <= 5; i++) {
    // start value; condition; change each time
}

2. while loop

Use when you do not know how many times to repeat.

let i = 1;
while (i <= 5) {
    i++;
}

3. do...while loop

Runs the body at least once, then checks the condition.

4. for...of loop

The easiest way to go through an array.

5. for...in loop

Goes through the keys (property names) of an object.

6. break and continue

  • break — stops the loop completely
  • continue — skips to the next iteration
