11. Fetch and APIs

API = Application Programming Interface. An API is a URL that gives you data when you request it. The most common format returned today is JSON.

This example uses the free test API jsonplaceholder.typicode.com. An internet connection is required.

1. What fetch() does

fetch(url)
    .then(response => response.json())   // convert the response to a JavaScript object
    .then(data => { ... })                // do something with the data
    .catch(error => { ... })              // handle any error

fetch() always returns a Promise, because the data has to travel over the internet and that takes time. See the 12_Promises example for the full picture.
