6. Arrays

An array stores multiple values in one variable, in order.

let fruits = ["Apple", "Banana", "Mango"];

1. Creating an Array

  • let arr = [10, 20, 30];
  • let arr = new Array(10, 20, 30); (less common)

2. Accessing Items

Indexing starts at 0. So the first item is arr[0].

  • arr.length — how many items
  • arr[arr.length - 1] — the last item

3. Common Array Methods

MethodWhat it doesChanges the array?
push(x)Add to the endYes
pop()Remove from the endYes
unshift(x)Add to the startYes
shift()Remove from the startYes
slice(a, b)Copy a part of the arrayNo
concat(a)Join two arraysNo
indexOf(x)Position of an item (-1 if not found)No
includes(x)true / false if the item existsNo

4. Modern Array Methods (very important)

  • map() — transform every item, returns a NEW array
  • filter() — keep only items that pass a test
  • find() — the FIRST item that matches
  • reduce() — combine all items into one value
  • forEach() — just run a function on each item
  • sort() — sort the array

5. The Spread Operator (...)

Used to copy an array, merge arrays, or pass array items as function arguments.
