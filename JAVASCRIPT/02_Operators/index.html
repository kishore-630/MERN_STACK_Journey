2. Operators

Operators are symbols that perform operations on values.

1. Arithmetic Operators

OperatorMeaningExampleResult
+Add10 + 515
-Subtract10 - 55
*Multiply10 * 550
/Divide10 / 52
%Remainder (modulus)10 % 31
**Power2 ** 38

Important: % is very useful — it tells you if a number is even or odd, or which day of the week it is.

2. Assignment Operators

  • = assign, += add and assign, -= subtract and assign
  • *=, /=, %= work the same way

3. Comparison Operators

  • == loose equal (compares value only)
  • === strict equal (compares value AND type) — prefer this one
  • != and !== not equal
  • >  <  >=  <=

4. Logical Operators

  • && AND — true when BOTH sides are true
  • || OR — true when AT LEAST ONE side is true
  • ! NOT — flips true to false and false to true
